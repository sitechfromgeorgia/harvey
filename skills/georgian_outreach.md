# ქართული B2B მიმოწერა — cold email, რომელიც იკითხება

ეს ფაილი ცვლის `email_frameworks.md`-ის ინგლისურ ნაწილს, როცა ადრესატი
ქართული ბიზნესია. წესები უფრო მკაცრია, არა უფრო რბილი: ქართულ ბაზარზე
ერთი ცუდი წერილი უფრო ძვირია, ვიდრე ათი გამოტოვებული — ყველა ერთმანეთს
იცნობს და ბათუმში ორი კვირა საკმარისია, რომ „სპამერის" რეპუტაცია დაგემაგროს.

## ოთხი წესი, რომელიც ყველაფერზე მაღლა დგას

1. **თემა = კონკრეტული დაკვირვება, არა შეთავაზება.** „სასტუმრო გოგა —
   ჯავშნის გვერდი" კარგია. „თანამშრომლობის შეთავაზება" — არა.
2. **პირველი წერილი 60 სიტყვაზე ნაკლები.** ერთი დაკვირვება, ერთი კითხვა.
   ფასი, პაკეტი და „ჩვენი კომპანია 2019 წლიდან" — არა.
3. **ქართულად, ერთი ინგლისური სიტყვის გარეშე.** არა „landing page", არა
   „SEO", არა „digital". თუ ტერმინი აუცილებელია — ფრჩხილში ახსენი.
4. **პასუხი არასდროს გამოგონილ ფაქტზე.** დაკვირვება რეესტრიდან ან საიტიდან
   უნდა იყოს, არა ვარაუდი. „ვნახე, რომ საიტი არ გაქვთ" მხოლოდ მაშინ, როცა
   მართლა არ აქვს.

## რაზე დავწეროთ — სიგნალიდან პირველ წინადადებამდე

| სიგნალი | პირველი წინადადება |
|---|---|
| `GE_WEB_MISSING` (დადასტურებული) | „თქვენი სასტუმრო ბათუმში 2019 წლიდან მუშაობს, საიტი კი ვერ ვიპოვე — ონლაინ ჯავშანი საიდან მოდის?" |
| `GE_NEW_REGISTRATION` | „ახალი ბიზნესი ხართ — საიტი უკვე გაქვთ თუ ჯერ იწყებთ?" |
| `GE_SIZE` = მცირე + `GE_ACTIVITY` | „მცირე განთავსების ობიექტი ხართ, 5–10 ნომერი — Booking-ის საკომისიოს გარდა საკუთარი გვერდი გაქვთ?" |
| `RUNNING_META_ADS` | „Facebook-ზე რეკლამას ხართ, მაგრამ ბმული საიტზე არ მიდის — სად აგზავნით ხალხს?" |
| `NO_ONLINE_BOOKING` | „ჯავშანი ტელეფონით ხდება? რა ხდება ღამის 11-ზე მოსულ შეტყობინებასთან?" |
| `BLOG_STALE` | „ბლოგი 2023-ზე გაჩერდა — ვიცი, რომ დრო არ არის. ერთი კითხვა: ვინ წერს ახლა?" |

ერთი სიგნალი = ერთი წერილი. ორი დაკვირვება ერთ წერილში = ორი კითხვა =
ნულოვანი პასუხი.

## ტონი

- **„თქვენ" დიდი ასოთი** — ქართულ ბიზნეს მიმოწერაში ეს ნორმაა.
- **მოკლე წინადადებები.** ქართული წერილი, რომელიც სამ სტრიქონს სცდება,
  იკითხება როგორც ოფიციალური ბიუროკრატია.
- **„გამარჯობა [სახელი],"** — არა „ძვირფასო", არა „Hello".
- **ხელმოწერა:** სახელი, თანამდებობა, ტელეფონი. სამი სტრიქონი, არა ლოგო.
- **ბოდიში არა.** „ბოდიშს გიხდით შეწუხებისთვის" = დაუპატიჟებელი წერილის
  აღიარება. ნაცვლად: „ერთი კითხვა მაქვს, თუ დრო გაქვთ."

## აკრძალული ფრაზები (ავტომატურად იჭერს pre-send gate)

- „ვიმედოვნებ, კარგად ხართ" / „იმედია, კარგად ხართ"
- „მინდა შემოგთავაზოთ" / „ნება მომეცით შემოგთავაზოთ"
- „ჩვენი კომპანია არის წამყვანი" / „ინოვაციური" / „ერთადერთი"
- „ამ წერილის მიზანია"
- „თუ დაინტერესებული ხართ, დამიკავშირდით" (პასიური — კითხვა სჭირდება)
- ნებისმიერი წინადადება, რომელიც 3-ზე მეტ ციფრს შეიცავს პირველ წერილში

## ფასი — მხოლოდ მაშინ, როცა იკითხეს

პირველი წერილი ფასს არ ამბობს. მეორე — მხოლოდ დიაპაზონს: „300–500 ₾
ლენდინგი, 1,500 ₾-მდე სრული საიტი ჯავშნით". ზუსტი ციფრი წერილობით
შეთავაზებაში მოდის, სამი ვარიანტით (Basic / Standard / Premium) — ეს
ჩვენი წესია და მუშაობს.

## როცა პასუხი არ მოდის

- **48 საათი** — ერთი follow-up, იგივე თემით, 30 სიტყვა. არაფრის გამეორება.
- **+5 დღე** — მეორე follow-up, ახალი კუთხე (სხვა დაკვირვება), 25 სიტყვა.
- **+10 დღე** — გამოსამშვიდობებელი: „ხელს არ შეგიშლით — თუ ოდესმე
  დაგჭირდათ, ეს არის ჩემი ნომერი." და მეტი არა.
- სამი წერილი, მეტი არა. მეოთხე = ბლოკი.

## არხი — მეილი ყოველთვის არ არის საუკეთესო

ბათუმის მცირე ბიზნესში მეილს ხშირად არავინ კითხულობს; WhatsApp ან
ტელეფონი უფრო სწრაფად პასუხობს. მეილი პირველი ნაბიჯია მაშინ, როცა
რეესტრში მეილი არსებობს (`GE_EMAIL`), ხოლო ნომერი — როცა მხოლოდ
ტელეფონია (`GE_PHONE`). ორივე არხი ერთ ნაბიჯში არ გამოიყენო: ერთი
შეხება, ერთი არხი.

## კანონი და პერსონალური მონაცემები

რეესტრიდან აღებული ხელმძღვანელის სახელი პერსონალური მონაცემია.
გამოიყენე მხოლოდ ლეგიტიმური ბიზნეს-კონტაქტისთვის, არ ააწყო პროფილი,
არ გადასცე მესამე პირს. კომერციული მიმოწერის სამართლებრივი ჩარჩო —
სოულის საკითხია; ეჭვისას ჰკითხე მას, სანამ გააგზავნი.
